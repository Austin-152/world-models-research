# World Model Research Notes

Personal research notes by [Austin-152](https://github.com/Austin-152) on world models, VLA systems, memory modules, and robotics deployment.

中文版本: [README_zh.md](./README_zh.md)

## What this repository contains

This repository is a collection of self-study summaries, technical notes, and implementation-oriented reflections built from papers, engineering docs, and open-source projects in embodied AI.

## Core topics

- Vision-Language-Action (VLA) models for robotic control
- world models, including latent dynamics and diffusion-based approaches
- 3D scene representations such as point clouds, scene graphs, NeRF, and Gaussian Splatting
- memory mechanisms for long-horizon robotics tasks
- training strategies, sim-to-real transfer, and deployment trade-offs
